# Support

Use GitHub issues for reproducible bugs and concrete feature requests. Search existing
issues first and use the appropriate issue form so maintainers have enough information
to help.

For general Spring AI questions, use the resources linked from the
[Spring AI Community](https://github.com/spring-ai-community) organization. Questions
about this starter's behavior may be opened with the question issue form.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md).
